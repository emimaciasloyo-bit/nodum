# Overall Goal

> [!WARNING]
> This is a first draft written from what's in the repo. Edit it in your own words — it's the note everything else hangs off.

## Mission (draft)
Use AI and automation to build useful products and workflows that run with as little manual work as possible — starting with **FinAI**, an AI-powered personal-finance web app.

## What "done" looks like
1. **FinAI is live and stable** on Vercel, with the AI features working through a secure server-side proxy. See [FinAI Overview](../01-FinAI-Website/FinAI-Overview.md).
2. **Repetitive work is automated** — content, market briefs, notifications, user onboarding — using Claude plus no-code tools (Make, Airtable, Notion…). See [Automation Ideas for FinAI](../02-AI-Automation/Automation-Ideas-for-FinAI.md).
3. **Knowledge is captured** here so each chat builds on the last instead of starting over. See [Chats](../03-Chats/INDEX.md).

## Guiding principles
- Ship small, working pieces; automate a step only after doing it by hand once.
- Keep API keys server-side; never in the browser.
- AI output in finance is educational, never advice — keep the disclaimers.

## Open questions
- Who is the target user (beginners? active traders?) and how will FinAI make money?
- Which automation should we build first?
