# Tools & Connectors

Tools connected to our Claude workspace (as of 2026-10-11) and what they're good for.

| Area | Tool | Use for |
|---|---|---|
| AI | **Claude** (API, Claude Code) | the brain: writing, analysis, coding, agents |
| Automation | **Make** | scheduled and webhook-driven workflows (scenarios) |
| Data | **Airtable**, **Notion** | content calendars, lead lists, knowledge bases |
| Hosting | **Vercel** | hosting FinAI and serverless functions |
| App builders | **Lovable** | quickly prototyping new full-stack apps |
| Code | **GitHub** | source of truth for FinAI and this vault |
| Comms | **Gmail**, Google Calendar, Google Drive | email automations, scheduling, files |
| Forms | **Tally** | waitlist / feedback forms |
| Design & content | Canva, Figma, Gamma, Adobe, Higgsfield | graphics, slides, video for marketing |
| Ads & analytics | AdWhispr, Windsor.ai | competitor ads, campaign data |
| Market data | **Finnhub** | prices and news inside FinAI |
| Notes | **Obsidian** | this vault |
